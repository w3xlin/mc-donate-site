# Сайт игрового сервера Minecraft (лендинг + магазин)

Статический сайт: чистый HTML/CSS/JS, без сборки и без зависимостей.
Готов к бесплатному размещению на **Cloudflare Pages**, GitHub Pages, Netlify и т. п.

> Это самостоятельный сайт «того же типа», что и популярные донат-магазины
> Minecraft-серверов: со своей структурой разделов, своим кодом и своими
> текстами. Чужой код, логотипы и тексты не копировались.

---

## Что внутри

```
index.html          — вся страница (шапка, герой, онлайн, магазин, топ, правила, партнёрка, корзина)
css/styles.css      — оформление (тёмная тема, адаптив)
js/config.js        — ★ ВСЕ настройки: название, IP, ссылки, режимы, тексты
js/data.js          — товары, топ игроков, лента покупок
js/app.js           — логика (магазин, корзина, таймер, копирование IP)
assets/favicon.svg  — иконка сайта
```

## Что уже работает

- Меню (в т. ч. мобильное), соцсети, кнопка корзины со счётчиком.
- Герой-блок с цифрами, которые «набегают» при загрузке.
- Блок онлайна с графиком за сутки (демо-данные).
- Кнопки копирования IP в буфер обмена.
- Лента «Недавние покупки».
- Таймер акции (обратный отсчёт).
- Магазин: 4 режима → категории → товары, скидки, плашки «Хит».
- Корзина (сохраняется в браузере), изменение количества, итог и выгода.
- Демо-оформление заказа с валидацией ника и email.
- Топ-10 игроков с подиумом.
- Блоки правил и партнёрки, футер.
- **Кастомный курсор** (кольцо + точка, растёт над кнопками) — включается/выключается в `js/config.js`.
- **Плавное появление секций** при прокрутке и лёгкая сетка на фоне.

## Как изменить под себя (5 минут)

1. Откройте **`js/config.js`** и поменяйте:
   - `serverName`, `serverShort`, `serverIp`
   - `supportUrl`, `discordUrl`, `telegramUrl`
   - тексты героя, правила, партнёрку, режимы и категории
2. В **`js/data.js`** замените демо-товары и топ игроков на свои.
3. Обновите страницу в браузере — всё подтянется автоматически.

Иконки товаров — эмодзи (⭐, 👑, 💎 …), их можно менять в поле `icon`.

## Настройки интерфейса

В `js/config.js`, блок `ui`:

- `customCursor` — `true`/`false` (кастомный курсор; на телефонах и при системном
  «уменьшить движение» он автоматически отключается).
- `cursorColor` — цвет курсора (по умолчанию зелёный `#22c55e`).
- `revealOnScroll` — плавное появление секций при прокрутке.

## Как посмотреть локально

Просто откройте `index.html` двойным щелчком. Для более точной проверки
(как на хостинге) запустите любой статический сервер:

```powershell
# если установлен Python
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Публикация на Cloudflare Pages (бесплатно)

### Вариант A. Быстро, перетаскиванием (без Git)

1. Зайдите на <https://dash.cloudflare.com> → **Workers & Pages** → **Create** →
   **Pages** → **Upload assets**.
2. Введите имя проекта (например, `my-minecraft-site`).
3. Перетащите **всю папку** с сайтом (или заархивируйте её и загрузите).
4. Нажмите **Deploy site**. Через несколько секунд сайт будет доступен по адресу
   вида `https://my-minecraft-site.pages.dev`.

### Вариант B. Через Git (обновления автоматически)

1. Создайте репозиторий на GitHub и залейте туда файлы сайта:
   ```powershell
   git init
   git add .
   git commit -m "website"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
   git push -u origin main
   ```
2. В Cloudflare: **Pages** → **Connect to Git** → выберите репозиторий.
3. Настройки сборки:
   - **Framework preset:** `None`
   - **Build command:** *(оставить пустым)*
   - **Build output directory:** `/` (корень)
4. **Save and Deploy**. Далее каждый `git push` будет обновлять сайт.

### Свой домен

В проекте Pages → **Custom domains** → **Set up a domain**, введите домен и
следуйте подсказкам (если домен уже в Cloudflare — привязка в один клик).

## Что осталось подключить (по желанию)

- **Оплата.** Сейчас форма заказа демонстрационная. Реальные платежи
  подключаются в `js/app.js` в функции `submitOrder()` — например, через
  ЮKassa, Robokassa, FreeKassa или СБП.
- **Реальный онлайн.** Цифры онлайна в `js/config.js` (`online`) — демо.
  Их можно получать с вашего API или через статистику сервера.
- **Топ игроков и покупки.** Данные в `js/data.js` — замените на реальные
  (например, выгрузкой из базы магазина).
