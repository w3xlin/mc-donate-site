# Сайт игрового сервера Minecraft (лендинг + магазин)

Статический сайт: чистый HTML/CSS/JS, без сборки и без зависимостей.
Размещён на GitHub Pages: **https://w3xlin.github.io/mc-donate-site/**

> Это самостоятельный сайт «того же типа», что и популярные донат-магазины
> Minecraft-серверов: со своей структурой разделов, своим кодом и своими
> текстами. Чужой код, логотипы и тексты не копировались.

---

## Что внутри

```
index.html          — главная (шапка, герой, онлайн, магазин, топ, правила, партнёрка, корзина)
top.html            — полный список «Богатейшие» с поиском по нику
rules.html          — правила сервера полностью
partners.html       — партнёрская программа
legal.html          — соглашение и конфиденциальность
thanks.html         — страница заказа (считывает последний заказ из браузера)
css/styles.css      — оформление (тёмная тема, адаптив, кастомный курсор)
js/config.js        — ★ ВСЕ настройки: название, IP, ссылки, режимы, тексты, оплата, акции
js/data.js          — товары, топ игроков, лента покупок
js/app.js           — логика главной (магазин, корзина, оформление, таймер)
js/site.js          — общий код внутренних страниц (шапка, футер, курсор, контент)
assets/favicon.svg  — иконка сайта
```

## Что уже работает

- Отдельные страницы: «Богатейшие» (с поиском), «Правила», «Партнёрка», «Документы», «Мой заказ».
- Меню (в т. ч. мобильное), соцсети, кнопка корзины со счётчиком и суммой (она общая для всех страниц).
- Герой-блок с цифрами, которые «набегают» при загрузке.
- Блок онлайна с графиком за сутки (демо-данные).
- Кнопки копирования IP в буфер обмена.
- Лента «Недавние покупки».
- Таймер акции (обратный отсчёт).
- Магазин: 4 режима → категории → товары, скидки, плашки «Хит», остаток на складе.
- **Карточка товара**: выбор срока действия для привилегий (30 дней / 90 / навсегда), количество, выгода.
- Корзина (сохраняется в браузере): изменение количества, итог, экономия.
- **Оформление заказа**: промокод, скидка за объём, бонусные монеты, способы оплаты с комиссией, минимальная сумма, валидация ника и email.
- **Экран «Оплата прошла»**: номер заказа, состав, бонус, чек. Сохраняется в `localStorage` и показывается на `thanks.html`.
- Топ-10 игроков с подиумом, блоки правил и партнёрки, футер.
- **Кастомный курсор** (кольцо + точка, растёт над кнопками) — включается/выключается в `js/config.js`.
- **Плавное появление секций** при прокрутке и лёгкая сетка на фоне.

## Как изменить под себя (5 минут)

1. Откройте **`js/config.js`** и поменяйте:
   - `serverName`, `serverShort`, `serverIp`
   - `supportUrl`, `discordUrl`, `telegramUrl`
   - тексты героя, правила, партнёрку, режимы и категории
   - `payments` — способы оплаты и их комиссии
   - `promoCodes` — промокоды (демо: `FUN10`, `MINE15`)
   - `volumeDiscounts` — пороги скидки за объём
   - `bonus` — бонусные монеты за покупку
   - `durations` — сроки действия привилегий и множители цен
   - `rulesFull`, `legal` — полные тексты правил и документов
2. В **`js/data.js`** замените демо-товары и топ игроков на свои.
3. Обновите страницу в браузере — всё подтянется автоматически.

Иконки товаров — эмодзи (⭐, 👑, 💎 …), их можно менять в поле `icon`.

## Настройки интерфейса

В `js/config.js`, блок `ui`:

- `customCursor` — `true`/`false` (кастомный курсор; на телефонах и при системном
  «уменьшить движение» он автоматически отключается).
- `cursorColor` — цвет курсора (по умолчанию зелёный `#22c55e`).
- `revealOnScroll` — плавное появление секций при прокрутке.

## Как посмотреть локально

Просто откройте `index.html` двойным щелчком. Для более точной проверки
(как на хостинге) запустите любой статический сервер:

```powershell
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Публикация на GitHub Pages (уже сделано)

Репозиторий: `w3xlin/mc-donate-site` (ветка `main`), сайт по адресу
`https://w3xlin.github.io/mc-donate-site/`. Обновление файлов — через
GitHub Contents API (скрипт деплоя в `dist/`-процедуре) или вручную:
GitHub → репозиторий → **Add file / Edit** → **Commit changes**.

Чтобы обновить сайт с git (если git установлен):

```powershell
git add .
git commit -m "update"
git push origin main
```

Файл `.nojekyll` в корне нужен, чтобы GitHub Pages отдавал файлы
с подчёркивания (`_headers`).

### Альтернатива: Cloudflare Pages / Netlify

Загрузите содержимое папки `dist/` (или архив) через интерфейс
Cloudflare Pages (**Upload assets**) или Netlify **Deploy folder**.

## Что осталось подключить (по желанию)

- **Оплата.** Сейчас форма заказа демонстрационная (с промокодами, комиссией
  и бонусами работает). Реальные платежи подключаются в `js/app.js` в
  функции `submitOrder()` — например, через ЮKassa, Robokassa, FreeKassa или СБП.
- **Реальный онлайн.** Цифры онлайна в `js/config.js` (`online`) — демо.
  Их можно получать с вашего API или через статистику сервера.
- **Топ игроков и покупки.** Данные в `js/data.js` — замените на реальные
  (например, выгрузкой из базы магазина).
